# Лендинг «Время шоу»: аниматоры и детские праздники, Ангарск и Усолье-Сибирское

Готовая к публикации одностраничная вёрстка для vremya_show38: HTML, отдельные CSS и JS, оптимизированные изображения и видео, файлы SEO и GEO.

## Структура
```
index.html             — страница (10 блоков)
css/style.css          — стили
js/main.js             — бургер-меню, фильтр каталога, афиши, конструктор цены, слайдер отзывов, видео, форма
img/                   — логотип, дракон, фото (WebP + JPG), карточки и афиши 27 программ
video/                 — 6 роликов (H.264, грузятся только по клику)
privacy.html           — политика конфиденциальности (заполнить реквизиты)
robots.txt, sitemap.xml, llms.txt, manifest.webmanifest, .htaccess, favicon.ico, иконки
SEO.md                 — семантическое ядро и чек-лист продвижения
```

## Блоки
1. Hero: H1 с городами, коллаж фото, ключевые факты
2. Почему мы: 4 преимущества
3. Каталог: 27 программ, фильтр («Малышам», «Девочкам», «Мальчикам», «Подросткам», «Вау-шоу», «Большие форматы»), афиша во всплывающем окне
4. Большие праздники: выпускные, пижама пати, пена MAXI, тимбилдинг
5. Конструктор праздника: программа, варианты и дополнения, итоговая цена
6. О команде и закулисье (видео)
7. 4 шага заказа (часы, стрелка идёт при прокрутке)
8. Слайдер отзывов
9. FAQ (разметка FAQPage)
10. Заявка: форма и контакты

Меню-бургер на мобильных, нижняя панель «Позвонить / Забронировать», адаптив от 320 px. Проверено в Chrome (десктоп и мобильная эмуляция). Используется только стандартный CSS/JS без библиотек, с префиксами для Safari (iOS) и запасными вариантами для старых браузеров.

## Перед публикацией
- **Домен.** Заменить `https://vremya-show38.ru/` на реальный в `index.html`, `robots.txt`, `sitemap.xml`, `llms.txt`.
- **Отзывы.** В блоке «Отзывы» стоят шаблоны (`data-sample`): подставить реальные отзывы клиентов.
- **Заявки.** По умолчанию форма собирает текст заявки, копирует его и предлагает отправить в Telegram, MAX, VK или позвонить. Чтобы заявки приходили автоматически, укажите URL обработчика (Telegram-бот, CRM) в `js/main.js` → `CONFIG.endpoint`.
- **Аналитика.** Вставить Яндекс Метрику и задать `window.YM_ID`. Цель `order` уже настроена.
- **privacy.html.** Вписать ФИО / ИНН оператора.
- Цены и состав программ взяты из прайса (ноябрь 2026). Распределение программ по фильтрам (малышам, девочкам и т.д.) нужно согласовать с заказчиком.
